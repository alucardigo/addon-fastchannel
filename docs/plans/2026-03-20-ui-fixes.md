# Fastchannel Addon UI Fixes Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Fix layout and alignment issues across the Fastchannel addon HTML pages (dashboard, pedidos, config, estoque, precos).

**Architecture:** We will adjust the CSS files/inline styles and HTML structures in the `vc/src/main/webapp/html5/fastchannel` directory. We will improve layout using CSS Flexbox/Grid for responsiveness and alignment.

**Tech Stack:** HTML5, CSS3, Vanilla JS.

---

### Task 1: Fix `dashboard.html` Layout

**Files:**
- Modify: `vc/src/main/webapp/html5/fastchannel/dashboard.html`

**Step 1: Fix Amostra Status grid**
- Check `<div class="orders-split">` and adjust `gap` or `grid-template-columns` so `Amostra Status` is not squished.
- Expand the `.stat-row-value` to have enough width.

**Step 2: Fix Progress Bar alignment**
- Adjust `margin` and `padding` of `<div class="progress-bar">` and labels in the `Operações` card for proper alignment.

### Task 2: Fix `config.html` Layout

### Task 3: Fix `pedidos.html` Layout

**Files:**
- Modify: `vc/src/main/webapp/html5/fastchannel/pedidos.html`

**Step 1: Widen Filter Inputs**
- Increase `min-width` of `.form-input` within `.filters` to at least `180px` for Date and Text inputs.
- Ensure the "Filtrar" `.btn` has `padding: 10px 24px;` and matches the height of inputs.

**Step 2: Standardize Status Pills**
- Review `.pill` CSS classes (`.success`, `.warning`, etc.) and ensure padding `padding: 4px 12px;` and font-sizes are identical across all states.

**Step 3: Center Action Buttons**
- Add CSS class `.text-center { text-align: center; }` to the `th` and `td` of the 'Ações' column.

---

### Task 4: Fix `estoque.html` Layout

**Files:**
- Modify: `vc/src/main/webapp/html5/fastchannel/estoque.html`

**Step 1: Fix Filters Layout**
- Force `.filters` to `flex-wrap: wrap; gap: 16px;`. If input fields are cramped, force `.filter-group` to `flex: 1; min-width: 200px;`.

**Step 2: Standardize Action Buttons**
- Review the `Ações` column and `.actions-row`. Ensure buttons `.btn-primary`, `.btn-secondary` have consistent `border-radius`, `height`, and `padding`. Update colors if any arbitrary blue/cyan inline styles exist.

---

### Task 5: Fix `precos.html` Layout

**Files:**
- Modify: `vc/src/main/webapp/html5/fastchannel/precos.html`

**Step 1: Align Grid Filters**
- Adjust `.filters` or `.form-row` to use CSS Grid `grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));` to properly distribute on multiple lines without orphaned solitary inputs.

**Step 2: Fix Select Width**
- Set `max-width` on the "Fonte de Dados" select to match other inputs, or wrap it in a flex container so it doesn't stretch 100% of the screen.
